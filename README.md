## 👨‍💻 Sobre mí

Soy **desarrollador de software**, titulado en Desarrollo de Aplicaciones Multiplataforma (DAM) y actualmente ampliando mi formación en Desarrollo de Aplicaciones Web (DAW).

Me interesa especialmente el **desarrollo Full Stack**, la programación backend y la creación de aplicaciones que aporten soluciones reales.

He trabajado en proyectos académicos y personales que abarcan aplicaciones web, desarrollo de videojuegos, gestión de datos y digitalización de negocios.

Actualmente estoy centrado en:

- 🚀 Desarrollar aplicaciones con **React, Next.js y TypeScript**.
- ☕ Profundizar en el desarrollo backend con **Java y Spring Boot**.
- 🗄️ Mejorar mis conocimientos de bases de datos y APIs REST.
- 🧩 Aplicar buenas prácticas, arquitectura y código mantenible.
- 🤝 Seguir creciendo profesionalmente en equipos de desarrollo.
